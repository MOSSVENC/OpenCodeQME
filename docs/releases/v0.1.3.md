# OpenCodeQME v0.1.3 — MV3 Browser Extension

## 中文

### OpenCodeQME v0.1.3 发布说明

此次版本主要适配 2026 年 9 月之后改版的 OpenCode Console，并修正旧版成本换算错误。

#### 新版 Console 兼容

- 工作区和账户识别切换到 `GET /console/api/me/orgs`。
- 工作区请求统一携带 `x-org-id`。
- Go 额度读取切换到 `GET /console/api/go/status?fresh=true`，解析 `access.meters.fiveHour/week/month` 中的 `usedMicroCents`、`limitMicroCents` 和 `resetsAt`。
- 用量统计切换到 `/console/api/usage/summary`、`/usage/models` 和 `/usage/cost-by-day` 的 30 天汇总。
- 旧版 Dashboard HTML 与 `/_server` 解析路径保留为 fallback。

#### 修复与界面

- 修正成本单位：`1 USD = 100,000,000 micro-cents`，修复旧版费用少显示 10 倍的问题。
- 已有 IndexedDB 记录在读取时按 `cost_raw` 自动修正成本。
- 新版接口不提供逐条请求记录，界面会明确显示按天/按模型汇总的限制。
- 总览、模型统计、每日趋势和 30 天模型汇总适配新版数据。

#### 构建与测试

- 新增纯 Node ZIP 打包器，不再依赖系统 `zip` 命令。
- 新增纯 Node CRX3 打包器；没有 Chromium 时也能生成 CRX，并自动校验签名和扩展 ID。
- 新增新版 Console API、Go meters、30 天汇总和成本单位测试。
- `npm test`、所有 JS/MJS 语法检查和 CRX3 验签通过。
- 版本更新为 `0.1.3`，`manifest.json` / `package.json` 同步更新。

#### 发布资产

- `opencodeqme-extension-0.1.3.zip`
- `opencodeqme-extension-0.1.3.crx`

## English

### OpenCodeQME v0.1.3 Release Notes

This release adapts OpenCodeQME to the OpenCode Console redesign from September 2026 and fixes the legacy cost conversion error.

#### Console v2 compatibility

- Account/workspace discovery now uses `GET /console/api/me/orgs`.
- Workspace-scoped requests send `x-org-id`.
- Go quota now comes from `GET /console/api/go/status?fresh=true`, reading `usedMicroCents`, `limitMicroCents`, and `resetsAt` from `access.meters.fiveHour/week/month`.
- Usage stats now use the 30-day aggregates from `/console/api/usage/summary`, `/usage/models`, and `/usage/cost-by-day`.
- The legacy Dashboard HTML and `/_server` parsers remain available as fallbacks.

#### Fixes and UI

- Corrected the cost unit to `1 USD = 100,000,000 micro-cents`, fixing costs that were displayed 10x too low.
- Existing IndexedDB records are normalized from `cost_raw` when read.
- The new API no longer exposes per-request records, so the UI clearly states that only daily/model aggregates are available.
- Overview, model stats, daily trends, and 30-day model summaries now consume the new aggregate data.

#### Build and tests

- Added a pure Node ZIP writer, removing the system `zip` dependency.
- Added a pure Node CRX3 packer that works without Chromium and verifies the signature and extension ID.
- Added coverage for Console API discovery, Go meters, 30-day aggregates, and the corrected cost unit.
- `npm test`, all JS/MJS syntax checks, and CRX3 verification pass.
- Bumped the version to `0.1.3` and synchronized `manifest.json` / `package.json`.

#### Release assets

- `opencodeqme-extension-0.1.3.zip`
- `opencodeqme-extension-0.1.3.crx`
